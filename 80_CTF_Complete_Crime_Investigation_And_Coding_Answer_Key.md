## 1. EXECUTIVE INVESTIGATION BRIEFING

At **02:13 AM**, the National Applied Research Consortium receives a single encrypted distress packet from its central evidence archive. The message contains only seven words:

> **“EIGHTY CASES. ONE HIDDEN HANDOFF. FIND THE PATTERN.”**

The Consortium is not an ordinary laboratory. Its divisions span cybersecurity, artificial intelligence, machine learning, data science, electronics, embedded systems, IoT, blockchain, robotics, aerospace systems, and nanotechnology. Over the previous twelve months, eighty apparently unrelated technical incidents were reported across these divisions.

Every investigation was previously closed as an isolated incident: a server breach, a manipulated AI diagnostic model, a forged financial transaction, a compromised sensor, a stolen nano-sample, an erratic industrial robot, a corrupted flight telemetry feed, and dozens more. Different victims. Different divisions. Different technologies. Different investigators.

A forensic re-analysis discovered that every single investigation contains a subtle technical irregularity that was never significant enough to become the central finding: a timestamp jitter, a hash fragment, a device identifier, a statistical outlier, a model version anomaly, a telemetry skew, or a transaction nonce.

Individually, these fragments mean almost nothing. Together, they form an unbreakable cryptographic and physical chain.

## 2. INVESTIGATION RULES & ARCHITECTURE

### Fundamental Rules

1. **Evidence outranks assumptions**: An account name is not proof of identity. AI confidence is not proof of guilt. A maintenance window is not proof of participation. A matching timestamp is not automatically causation. Every conclusion must be derived from independently verified technical evidence.
2. **Independent solvability**: Every single case is self-contained. A participant or investigator can solve any individual case without needing prior knowledge from another. The cross-domain link appears only through the **evidence token** produced after each case is verified.
3. **Deterministic output**: Flags are computed directly from the evidence dataset. No culprits are hard-coded.
4. **Final Principle**: *The crime is solved when another investigator can repeat the analysis and reach the exact same evidence-based conclusion.*

### How the 80 Cases Connect

- **Cases 01–20**: Establish original incidents and recover initial digital footprints.
- **Cases 21–40**: Expose mathematical, electronic, and data anomalies in physical and machine-learning systems.
- **Cases 41–60**: Correlate distributed failures across IoT, networks, and blockchain ledgers.
- **Cases 61–79**: Trace kinetic consequences across robotics, aerospace telemetry, and nanotechnology fabrication.
- **Case 80**: Synthesizes the 79 verified evidence tokens into a unified directed evidence graph, executing canonical topological sorting and SHA-256 chain verification to release the master flag.

#### Incident Narrative & Scenario

#### Investigator Objective
Reconstruct the attack order and identify the first unauthorized session.

#### Input Contract & Specification
```text
Input: n followed by n records `time user process bytes`, sorted output by time; flag uses first record whose user is ADMIN? No. Detect first duplicate user+time?
```

#### Required Result & Constraints
- **Required Result**: Reconstruct chronological order and print the first event after sorting by timestamp.
- **Constraints**: Use deterministic processing. Preserve input order where timestamps tie. Do not assume an offender from an account name alone.

#### Deterministic Sample Test Case
**Sample Input**:
```text
3
100 admin bash 50
150 guest curl 10
100 admin ssh 80
```

**Expected Output**:
```text
FLAG admin
```

**Walkthrough / Explanation**:
Events sorted by time: [100 admin bash 50], [100 admin ssh 80], [150 guest curl 10]. The first duplicate (time, user) occurs at timestamp 100 with user admin.

#### Verified Python 3 Reference Solution
```python
import sys

def solve():
    data = sys.stdin.read().split()
    if not data:
        return
    n = int(data[0])
    idx = 1
    records = []
    for _ in range(n):
        t = int(data[idx])
        u = data[idx+1]
        p = data[idx+2]
        b = int(data[idx+3])
        records.append((t, u, p, b))
        idx += 4
    records.sort(key=lambda x: x[0])
    seen = set()
    for t, u, p, b in records:
        k = (t, u)
        if k in seen:
            print(f"FLAG {u}")
            return
        seen.add(k)
    print("FLAG NONE")

if __name__ == '__main__':
    solve()
```

#### Algorithmic Complexity & Notes
- **Complexity**: `Time: O(n log n) for sorting | Space: O(n) for seen set`

import sys

def solve():
    data = sys.stdin.read().split()
    if not data:
        return
    n = int(data[0])
    idx = 1
    last = {}
    for j in range(n):
        u = data[idx]
        loc = data[idx+1]
        h = int(data[idx+2])

def solve():

    if not data:
        return

        d.setdefault(u, set()).add(f)

import sys

def solve():

from collections import defaultdict

def solve():
    lines = [l for l in sys.stdin.read().splitlines() if l.strip()]
    if not lines:
        return
    n = int(lines[0])
    stats = defaultdict(lambda: {'tp': 0, 'fp': 0, 'fn': 0})
    for i in range(n):
        a, p, g = lines[1+i].split()
        a, p = int(a), int(p)
        if a == 1 and p == 1: stats[g]['tp'] += 1
        elif a == 0 and p == 1: stats[g]['fp'] += 1
        elif a == 1 and p == 0: stats[g]['fn'] += 1
    best_g = None
    min_f1 = 2.0
    for g, s in stats.items():
        tp, fp, fn = s['tp'], s['fp'], s['fn']
        f1 = (2 * tp) / (2 * tp + fp + fn) if (2 * tp + fp + fn) > 0 else 0.0
        if f1 < min_f1:

            best_g = g

        return

    best_pwr, best_k = -1.0, 0

    if not data:
        return

    g = [[] for _ in range(n)]
    deg = [0] * n

import sys, heapq

def solve():
    lines = [l for l in sys.stdin.read().splitlines() if l.strip()]
    if not lines:
        return
    R, C = map(int, lines[0].split())
    grid = [list(map(int, lines[1+r].split())) for r in range(R)]
    sr, sc = map(int, lines[1+R].split())
    tr, tc = map(int, lines[2+R].split())
    d = {(sr, sc): 0}
    q = [(0, sr, sc)]
    while q:
        w, r, c = heapq.heappop(q)
        if w != d.get((r, c), 10**18):
            continue
        if (r, c) == (tr, tc):
            print(w)
            return
        for dr, dc in ((1,0), (-1,0), (0,1), (0,-1)):
            nr, nc = r + dr, c + dc
            if 0 <= nr < R and 0 <= nc < C:
                nw = w + grid[nr][nc]
                if nw < d.get((nr, nc), 10**18):
                    d[(nr, nc)] = nw
                    heapq.heappush(q, (nw, nr, nc))
    print("-1")

    vals = list(map(float, lines[1].split()))
